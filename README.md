# Link Jump

一个纯前端的手动链接队列工具，适合需要逐条打开链接、完成页面内操作后再继续下一条的场景。

## 使用

1. 一行输入一个完整链接并保存（可随时点击“清空链接”，直接清空输入框、队列与进度）。
2. 点击“打开当前链接”，会在当前页面打开当前条。
3. 手动完成目标页面中的操作，返回此工具。
4. 点击“本条已完成，打开下一条”。

队列、当前进度和失败标记只保存在该访问设备的浏览器 `localStorage` 中，不会上传到服务器，也不会在不同设备之间同步。

## Vercel 部署

导入 GitHub 仓库后，Vercel 会将根目录作为静态站点部署：

- Framework Preset: `Other`
- Build Command: 留空
- Output Directory: 留空

本仓库没有环境变量、后端服务或数据库要求。
